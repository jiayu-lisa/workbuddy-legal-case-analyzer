# 模块 A：案情梳理与法律关系分层识别

## 一、适用时机与输入

- **触发**：用户首次粘贴案情，要求"梳理案情""分析法律关系""这个案子涉及什么关系"等。
- **输入**：用户粘贴的案件基本情况（案情叙述、合同片段、当事人陈述等）。
- **纪律**：遵循"请不要急于给出结论，先完成梳理"。本模块只做到"初步判断核心矛盾"为止，**一两句话概括，不展开法律论证**。深入分析留待模块 C/D。

## 二、方法论：以"分层"为主线

本模块的重点是**分层**——把一个杂糅的案情拆成四层结构，每层解决一个问题：

| 层次 | 回答的问题 | 产出 |
|------|-----------|------|
| 主体层 | 案件里有谁？各自什么身份、什么地位？ | 主体清单 |
| 关系层 | 主体之间存在哪几层法律关系？核心是哪层？ | 分层法律关系 + 关联说明 |
| 时间层 | 哪些关键节点改变了法律关系？各产生什么效果？ | 关键时间线 |
| 矛盾层 | 本案法律上的核心矛盾是什么？ | 核心矛盾概括 |

**分层识别的关键**：不要把所有主体、所有事实堆在一个"法律关系"里。真实的商事案件（尤其股权投资、对赌回购、股权转让类）往往同时存在多层关系——投资协议关系、股权转让关系、公司与股东关系、担保关系等，它们的主体、性质、产生依据各不相同，必须**逐层剥离**。

## 三、各层操作要点

### （一）主体梳理

1. 穷尽列出案件中出现的**所有**主体，包括未被用户明确点名、但依案情必然存在的主体（如目标公司、其他股东、担保人、股权受让人、继承人）。
2. 每个主体标注两类信息：
   - **身份**：投资人、创始股东、目标公司、控股股东、股权受让人、保证人、债权人、债务人等。
   - **在案件中的地位**：权利主张方 / 义务承担方 / 利害关系第三人 / 程序上的当事人地位（原告、被告、第三人）。
3. 主体身份可能存在多重性（如同一人既是创始股东又是回购义务人），须分别标注。

### （二）法律关系识别（分层）

1. **逐层识别**：本案涉及哪几层法律关系，逐一列出。每层写明：
   - **双方主体**：该层关系存在于谁与谁之间。
   - **法律性质**：投资协议关系、股权转让关系、公司与股东关系、担保关系、委托关系等。
   - **产生依据**：基于哪份合同、哪个行为、哪条法律规定（如"基于《增资协议》第 X 条""基于《公司法》关于股东权利的规定"）。
2. **关联与核心**：说明各层关系之间的关联（牵连、主从、并存、前提），并指出**哪一层是本案的核心法律关系**及理由。
3. 识别关系类型时，参考 `legal-relations-taxonomy.md` 的全领域清单，避免遗漏跨领域牵连。

### （三）关键时间线

1. 按时间顺序列出**影响法律关系变动**的关键节点，如：签约、出资、条件成就/未成就、股权转让、变更登记、主张权利、催告、起诉等。
2. 每个节点标注**可能产生的法律效果**（如"回购条件成就，回购义务可能被触发""股权变更登记完成，受让人取得股东资格""催告到达，诉讼时效中断"）。
3. 时间不明的节点标注"时间待核实"。
4. **用表格呈现**。

### （四）初步判断（核心矛盾）

用**一到两句话**概括本案法律上的核心矛盾。只点出对抗结构，不下结论、不展开。例如："本案核心矛盾在于：投资人主张的回购义务，是否因创始股东转让股权、丧失股东身份而消灭或转移。"

## 四、输出模板

严格按以下结构输出（分节标题 + 编号列表，时间线用表格）：

```
一、主体梳理
1. 【主体名称】：身份为……；在本案中的地位为……
2. 【主体名称】：……
（逐一列出，含未点名但必然存在的主体）

二、法律关系识别
1. 本案涉及以下 N 层法律关系：
   （1）【第 X 层：法律性质，如投资协议关系】
        - 双方主体：……
        - 法律性质：……
        - 产生依据：……
   （2）【第 X+1 层】：……（同上）
2. 各层关系之间的关联：……
   本案的核心法律关系是第 X 层（……），理由：……

三、关键时间线
| 序号 | 时间 | 关键节点 | 可能产生的法律效果 |
|------|------|----------|--------------------|
| 1 | | | |

四、初步判断
本案法律上的核心矛盾是：……（一到两句话）
```

## 五、质量自检

- [ ] 是否穷尽了所有主体，包括隐含的必然主体？
- [ ] 每层法律关系是否都写明了双方主体、法律性质、产生依据三要素？
- [ ] 是否明确指出了核心法律关系及理由？
- [ ] 时间线是否只保留"影响法律关系变动"的节点，而非流水账？是否每个节点都标注了法律效果？
- [ ] 初步判断是否控制在一两句话、未展开论证？
- [ ] 事实与法律是否分离？对不确定的信息是否标注"待核实/我不确定"？
